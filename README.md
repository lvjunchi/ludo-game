# 🎲 情侣飞行棋

一个情侣互动空间，包含飞行棋等互动玩法。纯前端实现，无需服务器，打开即玩。

## 🎮 在线体验

https://lvjunchi.github.io/ludo-game/

## ✨ 功能

- **飞行棋对战** — 双人轮流掷骰子走格子，触发自定义事件互动
- **3D 骰子** — 立方体旋转动画，带碰撞音效
- **主题切换** — 浅色/深色/橹穆（蓝粉）三套主题
- **自定义玩家** — 可修改名称和 Emoji 图标
- **游戏统计** — 自动记录总对局和各自胜场
- **格子事件** — 56 格自定义事件文本，支持浪漫/搞笑/冒险三组预设
- **胜利庆祝** — Canvas 烟花 + 彩带 + 安慰动画
- **动态背景** — 爱心/花瓣从上飘落
- **照片管理** — 玩家头像、相册（IndexedDB 存储）
- **成就系统** — 连胜、全勤等成就解锁
- **纪念日** — 记录恋爱天数
- **PWA 离线支持** — Service Worker 缓存，断网也可游玩
- **互动任务确认** — 点击完成或跳过后换人，返回首页可继续未完成的任务
- **完整备份** — 设置中导出 JSON，支持覆盖恢复与去重合并，便于迁移手机
- **高清相册** — 新照片最长边 1600px，头像 320px，优先 WebP
- **版本更新提示** — 新版本下载完成后提示更新，已保存的数据保留

## 🚀 运行

无需构建或安装，直接打开 `index.html` 即可。

测试 PWA 功能时需通过 HTTP 服务：

```bash
npx serve .
```

## 🏗️ 技术栈

纯 HTML + CSS + 现代 JavaScript，运行时零依赖、零构建工具。

- `localStorage` — 配置与数据持久化
- `IndexedDB` — 相册照片存储
- `Web Audio API` — 音效生成（无外部音频文件）
- `Canvas 2D` — 烟花庆祝特效
- `CSS 3D Transforms` — 3D 骰子
- `Service Worker` — 离线缓存

## 📁 项目结构

```
index.html         — 入口页面
sw.js              — Service Worker
manifest.json      — PWA 清单
css/
  style.css        — 全部样式（三主题 CSS 变量）
js/
  constants.js     — 棋盘路径数据、参数常量
  storage.js       — localStorage 封装
  db.js            — IndexedDB 封装
  board.js         — 棋盘与棋子动画
  events.js        — 格子事件与预设
  dice.js          — 3D 骰子
  ui.js            — 弹窗、首选项 UI
  audio.js         — 音效系统
  home.js          — 首页渲染
  movement.js      — 移动逻辑与胜负判定
  game.js          — 入口：状态管理、事件绑定
  backup.js        — 完整备份、校验、合并与恢复
  pwa.js           — 更新提示与 Service Worker 生命周期
```

## 💾 备份与恢复

首页 → 设置 → 备份与恢复 → 导出完整备份。文件含设置、玩家、统计、成就、相册、回忆，请保存在可靠位置。当前未结束的对局不包含在备份中。所有数据仍然仅保存在当前浏览器，不会自动上传或跨设备同步。

恢复前会先校验文件并显示照片和回忆数量。合并保留当前已有设置、补充缺失设置、对照片和回忆去重、合并成就与游玩日期；双方胜场分别取较高值，并重新计算总对局，不能用来精确相加两个设备上的独立对局。覆盖会替换当前保存的数据，操作前请先导出当前备份。文件上限 100MB。

旧照片不会重新压缩，也无法从原有 200px 数据恢复原图；可重新上传原图获得更高分辨率。旧版 57 格事件数据读取时兼容保留前 56 格。

## 🧪 验收与发布

`tests/browser-smoke.cjs` 使用 Playwright 和 Chrome 验证回合交互、备份迁移、重复合并、存储失败回滚、照片尺寸、手机宽度布局、GitHub Pages 子路径离线访问和更新切换。运行前需让 Node 能找到 Playwright；浏览器可通过 `CHROME_PATH` 指定。应用本身不需要测试依赖。

每次发布请递增 `sw.js` 的 `CACHE_NAME`，确保所有资源上传完整。页面与静态资源使用同一个已安装版本；新版本安装完成后显示更新提示。v2 首次升级自动激活，后续版本由用户点击更新。更新会重置未结束对局，已保存的照片、回忆和设置保留。

真机发布验收建议使用 Android Chrome 和 iPhone Safari 检查图片选择、下载 JSON、文件恢复、添加到主屏幕和断网重开。
